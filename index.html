CASE STUDY 01: High TCP Latency & Packet Retransmission Storm INC-WS-001
Severity: P1 High
Protocol: TCP (Port 443)
Filter: tcp.analysis.retransmission
Result: Resolved

• Symptom: Users experienced frozen web sessions and severe latency degradation connecting to internal cloud storage.

• Packet Capture Trace: Wireshark capture revealed 18.4% packet retransmissions (`[TCP Retransmission]`) and numerous duplicate ACKs (`[TCP Dup ACK]`) originating from Access Switch Port 14.

• Root Cause: A damaged patch cord between the switch and distribution patch panel was dropping frames on physical pin 3, forcing TCP sliding window exhaustion.

• Preventive Resolution: Replaced patch cord and implemented switchport CRC error alerting in ClickUp. Retransmissions dropped to <0.05%.

CASE STUDY 02: Intermittent DNS Query Timeouts & Retries INC-WS-002
Severity: P2 Medium
Protocol: UDP 53 (DNS)
Filter: dns.time > 0.1
Result: Resolved

• Symptom: Clients intermittently reported "Server not found" when accessing web applications.

• Packet Capture Trace: Filter `dns.flags.response == 0` matched queries without corresponding responses for 3.5 seconds, triggering exponential DNS retry spikes.

• Root Cause: Upstream ISP primary DNS forwarder was throttling recursive UDP requests during peak hours.

• Preventive Resolution: Configured dual upstream BIND9 forwarders with local caching enabled (`8.8.8.8` and `1.1.1.1`). Query latency dropped from 3500ms to 12ms.

Curated Wireshark Display Filter Cheat Sheet

High-efficiency display filters used in daily enterprise network support and ticket triage

TCP Retransmissions & Lost Segments Layer 4 Diagnostics
tcp.analysis.retransmission || tcp.analysis.lost_segment

Isolates packet loss and buffer overruns causing degraded throughput.

DNS Resolution Latency (>50ms) or Failures DNS / Name Resolution
dns.time > 0.05 || dns.flags.rcode != 0

Filters out slow DNS lookups and server failure / NXDOMAIN responses.

DHCP DORA Handshake Transaction DHCP IP Assignment
bootp.option.type == 53

Tracks DHCP Discover (1), Offer (2), Request (3), and Ack (5) packet stages.

TCP Reset (RST) Connection Aborts Firewall / Port Blocks
tcp.flags.reset == 1 && tcp.seq == 1

Identifies connections refused by host firewalls or closed ports.

Microsoft Outlook (IMAP/POP3/SMTP) Diagnostics Runbook

SOP for resolving enterprise email client authentication, certificate mismatches, and synchronization hang

1. Standard Port & Protocol Verification Matrix
Service Protocol Standard Port Encryption CLI Test Command
Incoming Mail IMAP 993 SSL / TLS `openssl s_client -connect mail.corp:993`
Incoming Mail POP3 995 SSL / TLS `openssl s_client -connect mail.corp:995`
Outgoing Mail SMTP 587 STARTTLS `openssl s_client -starttls smtp -connect mail.corp:587`
2. Steps to Resolve "Cannot Connect to Incoming Mail Server (0x80042108)"

• Step 1: Run `Test-NetConnection -ComputerName mail.corp.enterprise.local -Port 993` in PowerShell to verify Layer 4 firewall reachability.

• Step 2: Capture with Wireshark filter `tcp.port == 993`. If packet trace shows `[SYN]` followed by immediate `[RST, ACK]`, internal firewall or antivirus email shield is intercepting port 993.

• Step 3: Verify SSL certificate CN/SAN matches Outlook account domain name to prevent silent handshake abortion.

• Step 4: Rebuild corrupted `.OST` local cache file by renaming to `.bak` and allowing Outlook to perform a clean sync from IMAP server.

SQA Defect Lifecycle & Ticket Triage Standard (SOP)

5-stage incident management process applied in IT support ticket tracking (ClickUp/Jira)

Step 1: Intake

Log ticket ID, user environment (Windows/Linux), symptoms, and affected IP subnet.

Step 2: Reproduce

Replicate anomaly with ping, traceroute, and initial Wireshark packet capture.

Step 3: Isolate

Filter trace to determine failing OSI Layer (L1 Physical, L2 VLAN, L3 IP, L4 TCP, or L7 DNS/Mail).

Step 4: Resolve

Deploy configuration fix, patch cable replacement, or DNS record correction.

Step 5: Document

Compile formal SQA RCA report in ClickUp knowledge base to prevent reoccurrence.
